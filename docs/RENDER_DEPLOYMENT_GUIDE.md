# IntelliDesk — Render Deployment Guide (1-Click Blueprint)

This guide walks you through deploying the complete **IntelliDesk** platform to [Render.com](https://render.com) using the included `render.yaml` Blueprint specification.

---

## What Gets Provisioned

When you deploy this Blueprint, Render automatically sets up:
1. **Managed PostgreSQL 16**: Pre-configured database with `pgvector` extension for semantic AI embeddings.
2. **Managed Redis 7**: Private in-memory cache for 5-minute phone OTP TTL tokens and session storage.
3. **Backend Web Service (Spring Boot 3 / Java 21)**: Production Docker container connected to PostgreSQL and Redis.
4. **Frontend Static Site (React 18 / Vite)**: Globally distributed edge CDN with SPA routing rewrite and automatic SSL.

---

## Step-by-Step Deployment Instructions

### Step 1: Push Code to GitHub
Ensure your latest code with `render.yaml` is pushed to your GitHub repository:
- Repository: `https://github.com/Santhosh-1102/IntelliDesk`
- Branch: `main`

### Step 2: Open Render Dashboard
1. Go to [https://dashboard.render.com](https://dashboard.render.com) and log in (or sign up with GitHub).
2. In the top right corner, click **New +** and select **Blueprint**.

### Step 3: Connect Your GitHub Repository
1. Select the **IntelliDesk** repository (`Santhosh-1102/IntelliDesk`).
2. Give your blueprint instance a name (e.g. `intellidesk-production`).
3. Render will scan `render.yaml` and display the 4 components to be deployed:
   - `intellidesk-postgres` (Database)
   - `intellidesk-redis` (Cache)
   - `intellidesk-backend` (Web Service)
   - `intellidesk-frontend` (Static Site)

### Step 4: Configure Environment Variables
Render will prompt you for any variable marked `sync: false`:
- **`GEMINI_API_KEY`**: Paste your Google Gemini API key.
- **`JWT_SECRET`**: Automatically generated by Render with a secure cryptographic string.
- Database and Redis connection strings are **automatically wired up** via Render's internal private network.

### Step 5: Click "Apply"
1. Click **Apply Blueprint**.
2. Render will provision the PostgreSQL database and Redis instance, build the backend Docker image, and build the React frontend.
3. Once the build finishes (usually 3–5 minutes), Render will provide live URLs:
   - **Frontend**: `https://intellidesk-frontend.onrender.com`
   - **Backend**: `https://intellidesk-backend.onrender.com`
